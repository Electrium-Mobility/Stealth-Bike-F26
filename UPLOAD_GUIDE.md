# Upload guide

1. Open the team repository and check for existing `docs/electrical/` files. If the folder exists, reconcile rather than overwrite existing approved documentation.
2. Create branch `docs/electrical-harness-review-2026-11` from the team's current default branch.
3. Upload `docs/electrical/` from this package. GitHub renders `wiring_plan.md` with its linked `wiring_diagram.svg`; PNG and PDF are provided for easy sharing.
4. Use `PR_DESCRIPTION.md` as the Pull Request body; request Electrical and Firmware lead review.
5. Do not mark any BLOCKED item VERIFIED without evidence. Do not merge as an approved wiring schematic.

Direct public URLs will exist only after the files are actually committed. To share in Google Sheets, paste the GitHub file URL (for example the SVG file's URL after commit), or upload the PDF/PNG to Google Drive and use Share -> Copy link.
